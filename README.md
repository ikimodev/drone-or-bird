# 🛰️ منظومة الدفاع الجوي والرصد التكتيكي الذكي (C2 Anti-Drone & Avian Intelligence)

منظومة متطورة مدعومة بالذكاء الاصطناعي للتمييز الدقيق بين **الطائرات المسيرة (الدرون الانتحاري والمروحي)** و**الطيور والكائنات الحية في السماء**، مع القضاء التام على الإنذارات الكاذبة الناتجة عن فرد الأجنحة أو التحليق الشراعي.

---

## 🌟 أبرز مميزات الترقية (v2.0 Advanced C2)

1. **مصفوفة النماذج المدمجة (Multi-Spectral AI Ensemble)**:
   - نموذج متخصص في كشف مسيرات شاهد-136 والأجنحة المثلثية (`anti_drone_best.pt`) بدقة mAP 91.1%.
   - نموذج رصد الدرونات المروحية والتجارية الرباعية (`drone_model.pt`).
   - نموذج عالي الدقة للتشريح الحيوي للطيور (`yolov8m.pt`).
2. **عدسة التحليل المورفولوجي البصري (Optical Morphology Analysis)**:
   - تحليل هندسة الهدف (الانضغاط Solidity، عدد الرؤوس Vertices، استقامة الحواف Canny/Hough).
   - التمييز الفوري بين الهياكل الصلبة المثلثية (Delta-Wing / 3 Vertices) والأجنحة العضوية المنحنية (Avian / 6+ Vertices).
3. **محلل الحركة والرفرفة الحيوية (Kinematic Flapping Analyzer)**:
   - تتبع مسار الأهداف المستمر (Multi-Target Tracking) مع حساب السرعة وزاوية التوجيه (Azimuth Heading).
   - رصد تردد رفرفة الأجنحة الحيوية (2-8 Hz) عبر قياس تذبذب معامل النسبة العرضية `AR(t) = W(t)/H(t)`.
4. **شاشة القيادة والتحكم التكتيكية (C2 Command HUD & Web Dashboard)**:
   - واجهة ويب عسكرية تفاعلية بتصميم Cyberpunk ومؤثرات زجاجية داكنة.
   - شاشة رادار حية ثلاثية الأبعاد بمسح دوار ونقاط أهداف تفاعلية (حمراء للدرون، خضراء للطيور).
   - **عدسة الاستطلاع البصري المقرّب (Optical Forensics Zoom)**: تعرض صورة مكبّرة لكل هدف مرصود في السماء مع تصنيفه الدقيق وخصائصه الهندسية.
   - صفارة إنذار تكتيكية مدمجة عند رصد أي مسيرة معادية.
   - دعم كامل لجميع صيغ الصور بما فيها الصيغ الحديثة (AVIF, WebP, PNG, JPG) بالإضافة للصق المباشر `Ctrl+V`.

## 🚀 طريقة التشغيل السريع

### 1. تشغيل واجهة الويب ولوحة التحكم (الموصى بها):
انقر نقراً مزدوجاً على:
```bat
run_web.bat
```
أو عبر الطرفية:
```bash
python web_app.py
```
ثم افتح المتصفح على الرابط:
👉 **http://127.0.0.1:5000**

### 2. تشغيل نافذة سطح المكتب (Desktop OpenCV / Webcam):
انقر نقراً مزدوجاً على:
```bat
run.bat
```
أو عبر الطرفية مع الخيارات:
```bash
# فحص كاميرا البث المباشر (Webcam):
python main.py --source 0

# فحص فيديو أو صورة مع حفظ المخرج التكتيكي:
python main.py --source user_image.jpg --save output_c2.jpg
```

## 🛠️ الملفات الأساسية

- `defense_core.py`: نواة مصفوفة الذكاء الاصطناعي والتتبع الحركي والتحليل المورفولوجي.
- `hud_renderer.py`: محرك شاشة الرؤية البصرية التكتيكية (C2 Military HUD).
- `web_app.py`: خادم لوحة التحكم متعدد المسارات (Threaded C2 Web Dashboard).
- `main.py`: برنامج سطح المكتب للتشغيل المباشر عبر الكاميرا والملفات.
